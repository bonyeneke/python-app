# Python App

A simple Python microservice used to demonstrate
Platform Engineering with Backstage.

## Overview

This project demonstrates:

- Python application development
- Project folder structure
- Dependency management
- GitHub integration
- Backstage Software Catalogue registration
- Future CI/CD and Kubernetes deployments

## Project Structure

    python-app/
    ├── backstage/
    │   └── catalog-info.yaml
    ├── docs/
    │   └── index.md
    ├── src/
    │   └── app.py
    ├── requirements.txt
    └── README.md

## Getting Started

Install dependencies:

    pip install -r requirements.txt

Run the application:

    python src/app.py

Open http://localhost:8080.
